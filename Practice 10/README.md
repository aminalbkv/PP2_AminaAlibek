
# Practice 10 - Pygame

## 1. Racer

A racing game where the player avoids enemy cars
and collects coins.

Features:
- Player movement using arrow keys
- Random enemy car positions
- Randomly appearing coins
- Coin counter in the top right corner
- Collision detection
- Game over message

## 2. Snake

A classic snake game with levels and increasing speed.

Features:
- Snake movement using arrow keys
- Wall and body collision detection
- Random food generation
- Food does not appear on the snake
- Score and level counters
- Level increases every 4 collected foods
- Speed increases with each level

## 3. Paint

A simple drawing application.

Features:
- Pencil
- Rectangle
- Circle
- Eraser
- Color selection
- Shape preview

## Technologies

- Python
- Pygame
- Random module

## Conclusion

This practice demonstrates game development,
event handling, collision detection, random generation
and drawing tools using Pygame.
