
# TSIS 2: Paint Application

## Description

A Paint application developed using Python and Pygame.

The project includes drawing tools from Practice 10
and Practice 11, as well as extended TSIS 2 features.

## Features

- Freehand pencil drawing
- Straight line with live preview
- Rectangle
- Circle
- Square
- Right triangle
- Equilateral triangle
- Rhombus
- Eraser
- Color palette and color picker
- Three brush sizes: 2, 5 and 10 pixels
- Flood fill
- Text placement
- Save canvas as PNG
- Clear canvas

## Controls

- Mouse: select tools and draw
- 1: Small brush
- 2: Medium brush
- 3: Large brush
- Ctrl+S / Cmd+S: Save canvas
- Enter: Confirm text
- Escape: Cancel text
- Backspace: Delete a character

## Installation

pip install pygame

## Run

python3 paint.py
