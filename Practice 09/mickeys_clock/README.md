
# Mickey's Clock Application

A real-time Mickey Mouse clock created using Python and Pygame.

## Features
- Displays current system minutes and seconds
- Mickey Mouse image as clock background
- Right hand represents minutes
- Left hand represents seconds
- Clock numbers from 1 to 12
- Updates every second
- Uses pygame.transform.rotate()

## Technologies
- Python
- Pygame
- datetime

## How to Run

Install Pygame:

    python3 -m pip install pygame

Run the application:

    python3 main.py
