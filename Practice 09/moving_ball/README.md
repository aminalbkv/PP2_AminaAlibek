
# Moving Ball Game

## Description
A simple interactive game created using Python and Pygame.

## Features
- Red ball on a white background
- Movement using arrow keys
- Moves 20 pixels per key press
- Boundary checking
- Smooth rendering at 60 FPS

## Controls
- Up Arrow - Move up
- Down Arrow - Move down
- Left Arrow - Move left
- Right Arrow - Move right

## Technologies
- Python
- Pygame

## How to Run
Install Pygame:

python3 -m pip install pygame

Run the game:

python3 main.py
