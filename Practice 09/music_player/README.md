
# Music Player with Pygame

## Description
This project is a simple music player developed using Python and Pygame.

The application allows users to play, stop, and switch between audio tracks using keyboard controls.

## Features
- Play music
- Stop music
- Switch to the next track
- Switch to the previous track
- Display the current track name
- Display playback progress
- Show current time and track duration
- Manage multiple tracks using a playlist

## Keyboard Controls
- P - Play
- S - Stop
- N - Next track
- B - Previous track
- Q - Quit

## Technologies
- Python
- Pygame
- Mutagen

music_player/

## Music Files

The music files are not included in this repository.

To run the music player:
1. Create a folder named `music` inside `music_player`.
2. Add two MP3 files to the folder.
3. Rename them to `track1.mp3` and `track2.mp3`.

You can download royalty-free music from Pixabay:
https://pixabay.com/music/ 


## How to Run

Install dependencies:

python3 -m pip install pygame mutagen

Run the application:

python3 main.py
